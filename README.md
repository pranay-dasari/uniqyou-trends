# UniqYou

This repo holds two Streamlit projects.

| Project | What it does | Live app | Docs |
|---|---|---|---|
| **uniqyou's Instagram Post Review Tool** | Paste an Instagram post link, then upvote it and comment on it. Uses Meta's official oEmbed API, with data stored in Supabase. | [Open live app](https://uniqyou-trends-bzi3mwc43s4ejtefz4q4qe.streamlit.app/) | [instagram-review-tool/README.md](instagram-review-tool/README.md) |
| **UniqYou — Fashion Trend Intelligence** | Spots fashion keywords that are gaining momentum and recommends TEST / INCREASE / WATCH / PASS. | — | [uniqyou_trends/README.md](uniqyou_trends/README.md) |

Each project has its own `requirements.txt` and setup steps in its README.
